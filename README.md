# Digitaliseerimine.ee

Eraldi müügi- ja maandumisleht Eesti ettevõtte omanikule, kes tahab alustada praktilise digitaliseerimisega ühest konkreetsest tööst.

Fookus:

- paber, Excel, e-mail ja vana tarkvara;
- üks esimene töö, mitte suur IT-projekt;
- 1 tööpäeva jooksul esmane omaniku vastus;
- vajadusel suunamine Digiteekaart.ee toetuse eelhindamisele.

## Local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Environment

- `PUBLIC_GA_MEASUREMENT_ID` - GA4 measurement ID
- `PUBLIC_SITE_LEAD_WEBHOOK_URL` - n8n/Supabase/Resend lead webhook
